# AIH
Interfacing EMG Sensor with Arduino UNO
Aim / Objective

To interface an EMG (Electromyography) sensor with Arduino UNO to measure muscle activity and analyze bioelectrical signals.

Apparatus / Components Required
Arduino Uno
EMG Sensor Module (e.g., MyoWare Muscle Sensor)
EMG Electrodes
Jumper Wires
Breadboard
USB Cable
Laptop with Arduino IDE
Circuit Diagram / Setup
6
Connections:
EMG OUT → A0
VCC → 5V
GND → GND
Theory

Electromyography (EMG) measures electrical signals generated by muscle contractions. When muscles contract, electrical impulses are produced, which can be detected using electrodes placed on the skin.

The EMG sensor amplifies and filters these signals and outputs an analog voltage proportional to muscle activity. The Arduino reads this signal and sends it to a computer for visualization and analysis.

Procedure
Connect the EMG sensor to Arduino as per the circuit diagram.
Attach electrodes to the muscle (e.g., biceps).
Open Arduino IDE and upload the code.
Open Serial Plotter or Serial Monitor.
Set baud rate to 115200.
Contract and relax the muscle to observe signal changes.
Arduino Code (Basic EMG Monitoring)
const int emgPin = A0;

Observations
EMG signal increases during muscle contraction
Signal remains low during relaxation
Noise may occur due to movement or poor electrode placement
Result

The EMG sensor was successfully interfaced with Arduino UNO. Muscle activity was detected and visualized in real time.

Conclusion
EMG signals effectively represent muscle activity
Arduino enables real-time signal acquisition
The system can be extended for prosthetics and AI-based applications
