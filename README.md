# AIH
Practical 1:
Experiment: Design and Implementation of ECG Monitoring System using AD8232 Sensor and Arduino for AI-based Healthcare Applications
Aim / Objective

To design and implement an ECG monitoring system using the AD8232 sensor and Arduino to acquire real-time heart signals for further analysis and AI-based healthcare applications.

Apparatus / Components Required
Arduino Uno
AD8232 ECG Sensor Module
ECG Electrodes (RA, LA, RL)
Jumper Wires
Breadboard
USB Cable
Laptop with Arduino IDE
Circuit Diagram / Setup

Connections:
OUTPUT → A0
LO+ → D10
LO− → D11
3.3V → 3.3V
GND → GND

Theory
Electrocardiography (ECG) is a technique used to measure the electrical activity of the heart. The AD8232 sensor is a signal conditioning block designed for ECG and other biopotential measurement applications. It amplifies small electrical signals generated by heart activity and filters out noise caused by motion and power-line interference.

The ECG waveform consists of:
P wave – atrial depolarization
QRS complex – ventricular depolarization
T wave – ventricular repolarization

The Arduino reads analog ECG signals from the AD8232 module and transmits them to a computer for visualization and analysis.

Procedure
Connect the AD8232 sensor to Arduino as per the circuit diagram.
Attach ECG electrodes properly to the body (RA, LA, RL positions).
Open Arduino IDE and write/upload the ECG monitoring code.
Open Serial Plotter from Tools menu.
Set baud rate to 115200.
Observe the ECG waveform displayed in real-time.
Arduino Code
const int ecgPin = A0;
const int loPlus = 10;
const int loMinus = 11;

void setup() {
  Serial.begin(115200);
  pinMode(loPlus, INPUT);
  pinMode(loMinus, INPUT);
}

void loop() {
  if ((digitalRead(loPlus) == 1) || (digitalRead(loMinus) == 1)) {
    Serial.println("Leads Off!");
  } else {
    int ecgValue = analogRead(ecgPin);
    Serial.println(ecgValue);
  }
  delay(2);
}

Observations
ECG waveform (P, QRS, T waves) is observed in the Serial Plotter.
Signal amplitude varies depending on electrode placement.
Noise may appear due to movement or poor electrode contact.
Result

The ECG monitoring system was successfully implemented using the AD8232 sensor and Arduino. Real-time ECG signals were obtained and visualized.

Conclusion
The system effectively captures heart electrical activity.
AD8232 provides amplified and filtered ECG signals.
Arduino enables real-time data acquisition and visualization.
The system can be extended for AI-based diagnosis and remote healthcare monitoring.
